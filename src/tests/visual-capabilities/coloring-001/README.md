# VIS-COLOR-001 — BPMN in Color laboratory

Open `coloring-001.bpmn` in BPMNSM Editor. Use the context-pad color picker to change the Task fill/stroke, export BPMN, and verify that the BPMNDI shape carries `bioc:fill` / `bioc:stroke`. Re-import the exported BPMN and verify the same rendering. Publish it and verify the Hosted Viewer renders the colors without exposing the color picker.

This laboratory proves BPMNSM's generic coloring capability. EA/XMI recovery is deliberately out of scope.
