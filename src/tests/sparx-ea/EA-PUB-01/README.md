# EA-PUB-01 — Sparx EA publication transverse corpus

This corpus contains controlled vertical cases used to qualify the path from
Sparx EA exports to BPMNSM publication.

Cases follow the existing `EA-PRE-01/cases/<case>/` convention: `case.json`,
`input/`, `expected/`, optional `evidence/`, and a case README when procedural
context is required.

`publication-roundtrip-001` is the first controlled publication case and spans
EA-PUB-01 through EA-PUB-10. Its final acceptance oracle is the Hosted Viewer.
