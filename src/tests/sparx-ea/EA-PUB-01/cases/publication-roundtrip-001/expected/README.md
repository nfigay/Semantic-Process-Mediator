# Expected observations — before EA evidence

This file records expectations, not observed results.

- The baseline BPMN must remain the immutable control specimen.
- BPMN `documentation` and the manually created EA/UML Note must remain
  distinguishable during analysis.
- Incoming and EA-native Groups must be compared separately.
- Incoming `bioc` colors and the EA-edited color must be compared separately.
- Stereotypes and Tagged Values must be mapped by meaning, not merely by their
  EA storage representation.
- XMI-derived information may enrich the autonomous BPMN produced by BPMNSM,
  but XMI must not be required by Publisher or Hosted Viewer.
- No EA-side development is justified unless standard BPMN + standard XMI
  demonstrably fail to contain publication-required information.
